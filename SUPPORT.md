# Support

Where to take a question or a problem.

| You have                                                              | Go to                                                                                              |
| --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| A question about how something works, or a workflow you want to share | [Discussions](https://github.com/Shironex/maquette/discussions)                                    |
| An idea                                                               | Ideas in [Discussions](https://github.com/Shironex/maquette/discussions)                           |
| A bug in the app                                                      | The Bug report form on the [issue chooser](https://github.com/Shironex/maquette/issues/new/choose) |
| A model that comes out wrong, or a pipeline step that fails           | The Model or pipeline problem form on the same chooser                                             |
| A vulnerability                                                       | [SECURITY.md](SECURITY.md), never a public issue                                                   |

Before you file anything, the [documentation](https://shironex.github.io/maquette/) and the README
cover each pipeline step and the toolchain setup, and the app's toolchain check says which tools are
missing. A report is much quicker to act on with the Maquette version, your OS, the Blender version
and the run log from the Pipeline view; remove API keys and private paths first.

Maquette is maintained by one person, so replies are not instant.
