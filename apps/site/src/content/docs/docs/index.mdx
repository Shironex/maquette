## The pipeline

Six stages. Each asset moves along them on the Board.

<PipelineStrip>

1. [Concept](/docs/views/lab/)
   Codex CLI image jobs
2. [Refs](/docs/views/board/)
   picks copied into refs/
3. [3D model](/docs/start/first-project/#03-3d-model)
   Tripo, Meshy or by hand
4. [Blender](/docs/pipeline/build-scene/)
   headless build, bake, export
5. [Web](/docs/pipeline/compress/)
   Compress
6. [Ship](/docs/pipeline/ship/)
   into your site repo

</PipelineStrip>
