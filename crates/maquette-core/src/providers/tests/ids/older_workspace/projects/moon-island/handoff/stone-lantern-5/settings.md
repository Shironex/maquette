# stone-lantern-5 for Stone lantern

Make this model in the Meshy web app, then bring the GLB back to Maquette.

1. Open https://www.meshy.ai/workspace and start a new Image to 3D.
2. Upload front.png.
3. Enter these settings:

| Setting | Value | Note |
| --- | --- | --- |
| AI model | Meshy 7.1 |  |
| Remesh | Off |  |
| Texture | On |  |
| Texture size | 2K |  |
| PBR | On |  |
| Pose | As drawn |  |
| Texture prompt | weathered granite |  |

4. Download the result as GLB, named `maq_stone-lantern_v5_meshy`.
5. Maquette picks it up from Downloads. Or drop it on the Stone lantern card on the Board, or save it into the inbox as `maq_stone-lantern_v5_meshy.glb`.
