# stone-lantern-2 for Stone lantern

Make this model in the Tripo web app, then bring the GLB back to Maquette.

1. Open https://studio.tripo3d.ai and start a new Image to 3D.
2. Upload front.png.
3. Enter these settings:

| Setting | Value | Note |
| --- | --- | --- |
| Tab | HD Model |  |
| AI Model | H3.1 | model id v3.1-20260211 |
| Ultra Mesh Quality | Off |  |
| AI Complete | On | recommended |
| Texture | On |  |
| Texture Quality | 2K |  |
| Remove Lighting | On | recommended |
| PBR | On |  |
| Topology | Triangle | quads export FBX only |
| Polycount | 20000 | Studio has no adaptive |
| Generate in Parts | Off | recommended |
| Rig | None | skip Rig, export the model as is |
| Export | maq_stone-lantern_v2_tripo | GLB, with this file name |

4. Download the result as GLB, named `maq_stone-lantern_v2_tripo`.
5. Maquette picks it up from Downloads. Or drop it on the Stone lantern card on the Board, or save it into the inbox as `maq_stone-lantern_v2_tripo.glb`.
